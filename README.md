# Revo Café ☕

A responsive café website — menu, products, about and contact pages, built with HTML, CSS and JavaScript.

## 🔗 Live demo

**[revo-cafee-n1.vercel.app](https://revo-cafee-n1.vercel.app)**

## 📄 Pages

- `index.html` — Home
- `menu.html` — Menu
- `products.html` — Products
- `about.html` — About the café
- `contact.html` — Contact

## 🛠️ Tech

`HTML` `CSS` `JavaScript`

## ▶️ Run locally

Open `index.html` in your browser — no build step needed. Or serve it with any static server:

```bash
python -m http.server
```

Then open `http://localhost:8000`.
